# 社会 一問一答（中学受験 歴史・地理）

iPhoneのホーム画面に追加して使う、オフライン対応のWebアプリ（PWA）です。

## 機能
- 教科（歴史／地理／両方）、学年（小4まで／小5まで／小6まで）、難易度（基本・標準・応用）、時代・地域で絞り込み
- 出題形式：4択／文字入力（漢字指定。答えが文章の問題などは4択で出題）／手書き／答えを考えてから自分で採点
  - 手書き：書いた字と正解を見比べて自分で○×。自動読み取り（Googleの非公式の手書き認識。設定でオフにできる）の結果を参考に表示
- 学習記録：今日の問題数と正答率、連続学習日数、最近14日間のグラフ、分野ごとの正答率と「覚えた」数
- 復習
  - **今日の復習**：間隔反復。正解するたびに次の出題を 1→3→7→14→30→60日後 に延ばし、まちがえたら翌日にもう一度出題
  - **苦手克服**：まちがえた回数が多い問題から出題
  - 結果画面から「まちがえた問題をもう一度」
- 記録のバックアップ／復元（コピーした文字で保存）
- 🗾 地図チャレンジ：色付きの県を答える／地図をタップ（全国→地方を拡大→都道府県）／川・山脈・平野・半島・湖・島・海の印を答える
- 📈 雨温図：気象庁の平年値（1991〜2020年）から描いたグラフを見て、都市や気候区分を答える
- 📜 年表チャレンジ：出来事を古い順に並べかえ／年表のア〜エのどこに入るか

地図は Natural Earth（パブリックドメイン）をもとに作成。川・山脈の一部は略図です。

## ファイル
- `index.html` / `style.css` / `app.js` … アプリ本体
- `questions/core.js` … 分類の定義
- `questions/history.js` / `questions/geography.js` … 問題データ
- `questions/mapdata.js` … 日本地図データ、`questions/maps.js` … 地図・雨温図の問題、`questions/timeline.js` … 年表の問題
- `sw.js` / `manifest.json` / `icon-*.png` … オフライン対応・ホーム画面用

## 問題の追加
`questions/*.js` の各分類の配列の**末尾に**追加します（並び順で問題IDが決まるため、途中に入れたり消したりすると学習記録がずれます）。

```js
[学年, 難易度(1基本/2標準/3応用), "問題文", "正解", ["誤答1", "誤答2", "誤答3"], "解説(省略可)"],
```
